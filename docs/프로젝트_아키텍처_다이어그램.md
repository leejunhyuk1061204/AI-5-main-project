# AI 자동차 건강 관리 시스템 — 프로젝트 아키텍처 (Mermaid)

전체 시스템 구조, 계층, 데이터 흐름을 Mermaid 다이어그램으로 정리합니다.

## 4. 데이터 흐름 — 주행·텔레메트리

```mermaid
sequenceDiagram
    participant OBD as OBD-II 동글
    participant App as 모바일 앱
    participant API as Spring Boot API
    participant DB as PostgreSQL/TimescaleDB

    Note over OBD, DB: 주행 시작
    App->>API: POST /trips/start
    API->>DB: Trip 생성
    API-->>App: tripId

    loop 주행 중 (1초 주기)
        App->>OBD: PID 요청 (RPM, 속도 등)
        OBD-->>App: OBD 응답
        App->>App: 로컬 버퍼 적재
    end

    App->>API: POST /telemetry/batch (logs)
    API->>DB: ObdLog 저장
    API-->>App: 200 OK

    Note over App, DB: 주행 종료
    App->>API: POST /trips/end
    API->>DB: Trip 통계·운전점수 계산
    API-->>App: tripId, driveScore 등
```

## 5. 데이터 흐름 — AI 정밀 진단 (비동기)

```mermaid
sequenceDiagram
    participant App as 모바일 앱
    participant API as Spring Boot

    participant Consumer as AiDiagnosisConsumer

    participant AI as FastAPI AI 서버
    participant DB as DB

    App->>API: 진단 요청 (사진/음성/OBD)
    API->>MQ: DiagnosisTaskMessage 발행
    API-->>App: 202 ACCEPTED

    MQ->>Consumer: 메시지 수신
    Consumer->>API: processUnifiedFlow()
    API->>AiClient: Visual / Audio / Anomaly 요청
    AiClient->>AI: 각 API 호출
    AI-->>AiClient: 분석 결과
    AiClient->>AI: Comprehensive 통합 진단
    AI-->>AiClient: 최종 리포트
    API->>DB: DiagResult 저장
    API->>App: FCM 푸시 (진단 완료)
```

## 8. 요약 — 3계층 + 스토리지

```mermaid
flowchart LR
    subgraph Client["Client"]
        App[모바일 앱]
        OBD[OBD 동글]
    end

    subgraph Server["Server"]
        BE[Spring Boot]
        MQ[RabbitMQ]
    end

    subgraph AI["AI"]
        FA[FastAPI]
    end

    subgraph Storage["Storage"]
        DB[(PostgreSQL)]
        Redis[(Redis)]
        S3[S3/파일]
    end

    App <--> OBD
    App --> BE
    BE <--> DB
    BE <--> Redis
    BE --> MQ
    MQ --> BE
    BE --> FA
    BE --> S3
    FA --> S3
```

---

- **Client**: React Native 앱 + OBD-II(ELM327). Bluetooth로 실시간 차량 데이터 수집.
- **Server**: Spring Boot — 인증·차량·주행·텔레메트리·진단 요청 조율. RabbitMQ로 AI 작업 비동기 처리.
- **AI**: FastAPI — 시각(YOLO)·엔진 소리·OBD 이상 탐지·RAG/리포트.
- **Storage**: PostgreSQL(TimescaleDB) 메인 저장소, Redis 캐시/세션, S3(또는 로컬) 파일.
- **Emulator**: `emulator/run_emulator.py` + CSV 시나리오로 OBD 동글 없이 주행 시뮬레이션.

이 문서의 다이어그램은 GitHub/GitLab, Notion, VS Code Mermaid 확장 등에서 렌더링할 수 있습니다.
