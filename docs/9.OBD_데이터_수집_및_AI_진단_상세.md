# OBD 데이터 수집 항목 및 AI 진단 활용 가이드

본 문서는 시스템에서 수집하는 OBD-II 데이터 항목의 분류와, 각 항목이 AI(LSTM, XGBoost) 진단 및 소모품 수명 예측에 어떻게 활용되는지 상세히 정의합니다.

## 1. 데이터 수집 항목 분류

수집 데이터는 차량의 지원 범위와 수집 경로에 따라 세 가지 계층으로 구분됩니다.

### 1.1 표준 항목 (Standard PIDs)
가장 범용적인 데이터로, 대부분의 OBD-II 지원 차량(2010년식 이후)에서 공통적으로 수집 가능합니다.
- **주요 항목**: 엔진 RPM, 차량 속도, 냉각수 온도, 엔진 부하(Load), 배터리 전압, 연료 보정(Fuel Trim - Short/Long).
- **수집 주기**: 1Hz (1초 간격).
- **저장 위치**: `obd_logs` 테이블의 전용 컬럼.

### 1.2 추가 항목 (Extended Standard PIDs)
표준 프로토콜에 포함되어 있으나 차종/식에 따라 지원 여부가 상이한 항목입니다.
- **주요 항목**: 흡기 온도(IAT), 흡기압(MAP), 공기 유량(MAF), 스로틀 위치(TPS), 가속 페달 위치(D/E), 외기 온도.
- **수집 방식**: 연결 초기 `01 00`, `01 20` 등의 명령으로 지원 여부를 스캔한 후 동적으로 수집 큐에 포함.

### 1.3 제조사 특화 및 클라우드 데이터
표준 OBD-II Mode 01로는 수집이 어렵거나, 제조사 커넥티드 서비스(Smartcar 등)를 통해 가져오는 것이 유리한 데이터입니다.
- **주요 항목**: 타이어 공기압(각 바퀴 별), 브레이크 유압, 휠 스피드, 정확한 주행거리(Odometer), 연료 잔량(%).
- **저장 위치**: `cloud_telemetry` 테이블 또는 `obd_logs.json_extra`.

## 2. 데이터 활용 및 AI 진단 시나리오

### 2.1 표준 항목 기반 진단 (기본 성능)
표준 데이터 세트만으로도 LSTM-AutoEncoder는 데이터 간의 상관관계를 통해 핵심 이상 징후를 포착합니다.

| 분석 대상 | 진단 로직 (LSTM / Logic) | 기대 결과 |
|:---|:---|:---|
| **배터리** | 시동 시 전압 강하 기울기 및 회복 시간(Recovery Time) 분석 | 방전 위험 및 성능 저하 경고 |
| **엔진 부조** | 특정 부하(Load) 구간에서 RPM의 미세 변동성(Fluctuation) 포착 | 점화 플러그/코일 이상 징후 감지 |
| **냉각 시스템** | 외기 온도 대비 냉각수 온도의 정상 범위 도달 시간 추세 분석 | 서모스탯 고착 또는 냉각팬 고장 예측 |
| **연료 시스템** | 장기 연료 보정값(LTFT)의 지속적인 우상향(Positive Drift) 분석 | 인젝터 오염 또는 흡기 누설 추정 |

### 2.2 추가 항목 도입 시 고도화 (정밀 진단)
IAT, MAF, Pedal Position 등 추가 데이터가 확보되면 진단의 해상도가 비약적으로 향상됩니다.

| 분석 항목 | 고도화 내용 | 진단 가점 |
|:---|:---|:---|
| **흡기/터보** | MAF와 MAP 데이터를 대조하여 계산된 유량과 실제 압력 간의 불일치 분석 | 흡기 누설(Vacuum Leak) 및 터보차저 성능 저하 정밀 진단 |
| **스로틀계통** | 가속 페달 개방도(Pedal)와 실제 스로틀 열림(TPS) 간의 응답 지연 분석 | 스로틀 바디 카본 퇴적 및 관련 센서 이상 감지 |
| **연소 효율** | IAT(흡기온)와 가혹 주행 시의 부하 상관관계 분석 | 인터쿨러 성능 저하 및 연소 효율 최적화 가이드 제공 |
| **안전 점수** | 단순 속도 변화율이 아닌 실제 페달 가속/감속 시그널 기반 분석 | 급가속/급제동 판정의 정밀도 향상 (운전 점수 신뢰도 확보) |

## 3. 소모품 수명 예측 모델 (XGBoost) 연동

주행 종료 후 `trip_summaries`로 가공된 통계 데이터는 소모품별 마모도(Wear Factor) 계산의 핵심 입력값으로 사용됩니다.

1.  **엔진 오일**: 주행 중 평균 RPM과 엔진 부하의 적분값을 통해 단순 거리 기반보다 1.5배 정밀한 수명 예측.
2.  **냉각수**: `overheat_duration_sec`(95도 초과 지속 시간)를 누적 관리하여 산화 및 성능 저하 시점 예측.
3.  **브레이크 패드/타이어**: `hard_brake_count`와 `hard_accel_count`를 가중치로 사용하여 주행 스타일별 교체 주기 개인화.
