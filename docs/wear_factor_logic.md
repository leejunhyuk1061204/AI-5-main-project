# 소모품 수명(Wear Factor) 분석 알고리즘 설계서

이 문서는 차량의 주행 데이터를 기반으로 5대 주요 소모품의 마모도를 예측하는 `Wear Factor` 엔진의 알고리즘과 산출 공식을 설명합니다.

## 1. 개요
마모 계수(Wear Factor)는 주행 조건에 따라 소모품이 표준 상태 대비 얼마나 더 빠르게 또는 느리게 마모되는지를 나타내는 지표입니다.
- **1.0**: 표준 마모 속도
- **> 1.0**: 가속 마모 (예: 1.5는 표준보다 50% 빠르게 마모됨을 의미)
- **< 1.0**: 감속 마모 (예: 0.5는 표준보다 절반 속도로 마모됨을 의미)

---

## 2. 항목별 산출 로직

### ① 엔진 오일 (ENGINE_OIL)
엔진 오일은 주행 거리뿐만 아니라 엔진의 회전 수(RPM)와 공회전 시간에 큰 영향을 받습니다.

- **기본 거리 계수 ($K_{dist}$)**: `(현재 누적 주행거리 - 마지막 교체 시점 주행거리) / 10,000`
- **공회전 패널티 ($P_{idle}$)**: `1.0 + (공회전 비율 * 0.5)`
- **고회전 패널티 ($P_{rpm}$)**: `1.0 + max(0, (최대 RPM - 3000) / 5000)`
- **최종 공식**: $WearFactor = K_{dist} \times P_{idle} \times P_{rpm}$ (최대 3.0)

### ② 에어필터 (AIR_FILTER)
에어필터는 흡입 공기량(MAF, Mass Air Flow)의 효율성을 기반으로 상태를 추정합니다.

- **기본 거리 계수 ($K_{dist}$)**: `(현재 누적 주행거리 - 마지막 교체 시점 주행거리) / 15,000`
- **흡기 효율 ($E_{maf}$)**: `min(1.0, 평균 MAF / 20.0)`
- **최종 공식**: $WearFactor = K_{dist} \times (2.0 - E_{maf})$ (최대 3.0)

### ③ 냉각수 (COOLANT)
냉각수는 엔진 과열 여부와 가혹 온도 환경에 노출된 시간을 기준으로 계산합니다.

- **기본 거리 계수 ($K_{dist}$)**: `(현재 누적 주행거리 - 마지막 교체 시점 주행거리) / 40,000`
- **과열 발생 시 (95°C 초과)**:
  - **과열 손상 ($D_{heat}$)**: `1.0 + (과열 지속 분(min) * 0.5)`
  - **최종 공식**: $WearFactor = K_{dist} \times D_{heat}$ (최대 3.0)
- **정상 주행 시**:
  - **온도 패널티 ($P_{temp}$)**: `max(0, (평균 냉각수 온도 - 90) * 0.02)`
  - **최종 공식**: $WearFactor = K_{dist} + P_{temp}$ (최대 3.0)

### ④ 타이어 (TIRE)
타이어 마모는 급가속과 급제동 횟수 등 운전자의 공격적인 주행 습관에 비례합니다.

- **기본 거리 계수 ($K_{dist}$)**: `(현재 누적 주행거리 - 마지막 교체 시점 주행거리) / 50,000`
- **주행 공격성 지수 ($A$)**: `(급가속 횟수 * 0.6 + 급제동 횟수 * 0.4) / 주행 거리(km)`
- **최종 공식**: $WearFactor = K_{dist} \times (1 + A \times 3.0)$ (최대 3.0)

### ⑤ 브레이크 패드 (BRAKE_PAD)
브레이크 패드는 제동 시의 에너지량(속도의 제곱에 비례)과 주행 환경(시내/고속)을 고려합니다.

- **기본 거리 계수 ($K_{dist}$)**: `(현재 누적 주행거리 - 마지막 교체 시점 주행거리) / 60,000`
- **제동 에너지 지수 ($E_{brake}$)**: `급제동 횟수 * (평균 속도^2) / 10,000`
- **시내 주행 배수 ($M_{city}$)**: 평균 속도가 30km/h 미만인 경우 `1.3`, 그 외 `1.0`
- **최종 공식**: $WearFactor = K_{dist} \times (1 + E_{brake}) \times M_{city}$ (최대 3.0)

---

## 3. 데이터 보정
- 모든 마모 계수는 최소 **0.1** 이상의 값을 가지도록 보정됩니다.
- 교체 기록이 없는 경우 기본적으로 보수적인 수치(1.0 ~ 1.1)를 반환합니다.
