## 🔥 진행 중 및 예정 (In Progress & Todo)

### 🔗 백엔드-프론트엔드 연결 누락 (Backend-Frontend Integration Gaps)

#### ❌ 미연결 백엔드 API (프론트엔드 미구현)

**1. CloudAuth API (`/auth/cloud/**`) - 클라우드 차량 연동**
- [ ] `PATCH /auth/cloud/vin` - VIN 정보 업데이트
- [ ] `POST /auth/cloud/register` - 클라우드 차량 등록 (하이모빌리티)
- [ ] `POST /auth/cloud/sync` - 차량 데이터 강제 동기화
- [ ] `POST /auth/cloud/revoke` - 클라우드 차량 연동 해제
> **참고**: 하이모빌리티 클라우드 연동 기능은 현재 프론트엔드에 구현되지 않음

**2. Media API (`/media/**`) - 미디어 파일 업로드**
- [ ] `POST /media/upload` - 범용 미디어 파일 업로드
> **참고**: 현재 AI 진단 시 직접 multipart로 전송 중. 별도 업로드 API 미사용

**3. Admin Test API (`/admin/test/**`)** - 관리자 테스트용
- [ ] `POST /admin/test/insert-old-logs` - 테스트 데이터 삽입
- [ ] `POST /admin/test/trigger-cleanup` - 데이터 정리 스케줄러 강제 실행
> **참고**: 개발/테스트 전용이므로 프론트엔드 연결 불필요

#### ⚠️ 부분 미연결 API

**AuthController (`/api/v1/auth/**`)**
- [ ] `PATCH /api/v1/auth/fcm-token` - FCM 토큰 등록/업데이트
  - 백엔드 준비됨, 프론트엔드 `authApi.ts`에 함수 미구현
  - 푸시 알림 기능 구현 시 필요

**VehicleController (`/api/v1/vehicles/**`)**
- [ ] `DELETE /api/v1/vehicles/{vehicleId}` - 차량 삭제
  - 백엔드 준비됨, 프론트엔드 `vehicleApi.ts`에 함수 미구현
  - 차량 관리 페이지에서 삭제 기능 필요 시 구현

**MaintenanceController (`/api/v1/maintenance/**`)**
- [ ] `GET /api/v1/maintenance/{vehicleId}/maintenance` - 정비 이력 조회
  - 백엔드 준비됨, 프론트엔드 `maintenanceApi.ts`에 함수 미구현
  - **정비 이력 페이지 구현** 시 함께 연결 필요

**TripController (`/api/v1/trips/**`)**
- [ ] `POST /api/v1/trips/start` - 주행 시작
- [ ] `POST /api/v1/trips/end` - 주행 종료
  - 백엔드 준비됨, 프론트엔드 `tripApi.ts`에 함수 미구현
  - 현재는 자동 주행 생성이지만, 수동 주행 기록 기능 추가 시 필요
